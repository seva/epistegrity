# Pending Owner — Open Invocation Register

Home of every open human invocation (CYCLE.md Autonomy — Turk decomposition). Tier 1: the row schema below is machine-gated by the project's record-law suite. Tier 2: phrase resolution + allocation scan — METHODOLOGY.md Post-Phase Audit item 5 (procedural). An empty register is a valid state; rows that exist are bound. Resolved invocations are removed — the ruling, disposition, or packet lands in its own record home (issue, `docs/`), never here.

Row obligations:

- **Reserved class** — from the closed set (CYCLE.md Turk decomposition): sanction · secret minting · metric booking · mission disposition · coercion-scope designation · constitutional amendment. The constitutional home of the class is cited in the same cell.
- **Act statement** — one act, one line. A packet the act consumes must be complete before the row is an invocation; incomplete packets name the reclaimed machine work instead.
- **Packet pointer** — existence-gated for `docs/` targets; issue references accepted as declared (record-law gate precedent).
- **Score line** — V/P/C for the invocation at ripeness; provisional scores say so.
- **Concurrent motion** — never empty: a waiting state without concurrent motion is forbidden (CYCLE.md Autonomy).
- **Surfaced** — when the obligation arose and when it was registered; a bare surfacing predating the register is disclosed, not hidden.
